REGLES STRICTES :
- mismatch_type "none" : conserver tel quel (deja compatible avec le style)
- mismatch_type "surface" : personnaliser via DIY (couleur, tissu, quincaillerie - meme structure)
- mismatch_type "structural" : remplacer (materiau ou structure fondamentalement incompatible)
- Ne propose "structural" que si aucune action DIY ne peut reconcilier l element avec le style
- Pour les elements architecturaux (sol, murs), prefere "surface" avec l action la plus adaptee
- action_slug DOIT etre null si mismatch_type est "none" ou "structural"
- action_slug DOIT etre un slug de la liste disponible si mismatch_type est "surface"
- Une personnalisation n a de valeur que si le changement est NETTEMENT VISIBLE : ne propose JAMAIS de repeindre/teinter un element dans une couleur ou finition quasi identique a son etat actuel (ex. repeindre en blanc casse un meuble deja blanc) -> dans ce cas mismatch_type "none"
- Les equipements electroniques (television, ecran) ne se personnalisent ni ne se remplacent jamais (aucun interet deco) : toujours "none"

- PETITE DECO (cadres, tableaux, miroirs decoratifs, objets, plantes, coussins) — remaster 2026-07-10 : "none" UNIQUEMENT si elle s accorde deja au style cible ; sinon "structural" (elle sera RETIREE de la piece, pas remplacee — la nouvelle deco viendra de la mise en scene du style). Jamais "surface" sur la petite deco.
- MURS — couleur ASSUMÉE. Repeindre un mur clair dans un AUTRE ton clair (blanc cassé, crème, sable, beige, gris clair, taupe) ne se VOIT PAS sur le rendu : c est un échec, et le client paie un pot de peinture pour rien. RÈGLE ABSOLUE DE CONTRASTE : la couleur choisie doit trancher FORTEMENT avec la couleur ACTUELLE du mur décrite dans l élément (un mur gris clair ne devient JAMAIS sauge grisé ni beige sable — il devient terracotta, olive profond, bleu nuit… selon la palette). Si la palette du style contient au moins UNE teinte SATURÉE ou PROFONDE (terracotta, ocre, olive, sauge, vert, bleu, brun, bordeaux, noir…), tu DOIS choisir celle-là pour le mur — même si la palette contient AUSSI des neutres (Sand, Cream, Ivory en font presque toujours partie : ce sont des couleurs d appoint pour les TEXTILES, pas le mur). Le mur ne prend un neutre QUE si la palette est ENTIÈREMENT neutre. Nomme UNE couleur PRÉCISE avec son CODE HEX pris dans la palette du MOOD, dans action_label ET action_label_en quand il existe (ex. « Repeindre le soubassement en olive profond (#4A5D43) ») — le hex verrouille la teinte au rendu. Nomme la couleur (ex. « Repeindre les murs en terracotta chaud », pas « en teinte sable »). Si le mur a un soubassement mouluré ou des boiseries : traitement bicolore en UNE instruction (soubassement dans la teinte PROFONDE de la palette, partie haute plus douce).
- TEINTER du bois n est possible QUE sur du bois brut/teinte visible ; un meuble PEINT ne se teinte pas (la peinture bloque la teinte) → pour un meuble peint, seule une action de PEINTURE est valide.
